# PopulationModel
Acest proiect implementează un model matematic de evoluție a populației bazat pe matricea Leslie, utilizând concepte din Metode Numerice pentru a analiza dinamica pe termen lung a unei populații structurate pe clase de vârstă.

Modelul este inspirat din teoria dezvoltată de Patrick H. Leslie și pune accent pe legătura dintre valoarea proprie dominantă a matricei de tranziție și stabilitatea populației.
